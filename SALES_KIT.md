# InfoHub Sales Kit

## Short positioning

**InfoHub — Full-stack News & Knowledge Platform Foundation / MVP**

A Thai news, knowledge, and data platform foundation with public content pages, search, categories/tags, Appwrite authentication/database, editorial CMS, RSS/Atom draft-first ingestion, analytics, SEO routes, and Vercel deployment configuration.

Sell it as a **source-code/product foundation ready for buyer customization and production setup**, not as a live media business with guaranteed traffic, revenue, publisher licenses, or existing commercial traction.

## Important product facts

### Included

- Next.js 15 / React 19 / TypeScript
- Appwrite Auth + TablesDB
- Public Thai news/knowledge UI
- Search, categories, tags, article detail pages
- Login/register/password recovery flows
- Protected dashboard/profile/settings
- Editorial CMS
- Draft/review/publish/archive workflow
- Editorial audit/activity trail
- RSS/Atom ingestion
- Duplicate detection and ingestion history
- Lightweight article-view analytics
- Sitemap / robots / metadata / structured SEO foundations
- Vercel Cron configuration with Appwrite-backed scheduled ingestion
- Optional OpenAI editorial assistance
- Appwrite provisioning script
- CI verification and local verification scripts

### Buyer must configure

- Buyer-owned Appwrite project and credentials
- Buyer-owned Vercel project/team
- Public domain
- Email/auth configuration
- RSS/Atom sources and permissions
- Demo content replacement or labeling
- Privacy/Terms review
- Publisher/content/image licenses where required
- Commercial license/IP transfer terms

## What not to claim

Do not claim:

- guaranteed traffic
- guaranteed revenue
- existing paying customers
- publisher agreements
- licensed news content
- production-scale capacity without verification
- autonomous AI publishing
- legal compliance in a specific jurisdiction
- that demo articles prove real publisher relationships

## Final handover gate

Before closing a sale, verify:

1. Latest Vercel production deployment performs a real Next.js build.
2. Public homepage opens.
3. Appwrite-backed public content read path works.
4. Auth and protected routes work with a buyer-owned test account.
5. CMS create/edit/publish/archive works.
6. RSS/Atom ingestion works.
7. Cron configuration is verified.
8. Demo content is clearly labeled or replaced.
9. Buyer receives the repository and handover document.
10. Commercial license/IP transfer terms are documented separately.

## Security note

Never send Appwrite API keys, Vercel tokens, GitHub tokens, or other secrets in buyer messages. Use buyer-owned credentials for the handover. Any credential that was exposed outside the intended secret store should be rotated/revoked before final transfer.
